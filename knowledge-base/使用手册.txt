Ayer AI 智能对话助手 — 用户使用手册
版本：2.0 | 更新日期：2025年3月

==========================================================
第一章 快速开始
==========================================================

1.1 访问与界面布局
打开 Ayer 后，界面分为三个区域：
- 左侧边栏：历史会话列表、搜索入口、设置按钮
- 中央主区域：当前对话内容
- 底部输入区：消息输入框及功能按钮

1.2 发送第一条消息
在底部输入框中输入问题，按 Ctrl+Enter（或点击发送按钮）即可发送。
如需换行，直接按 Enter 键（可在设置中切换为"Enter 发送"模式）。

1.3 新建对话
点击左上角"新建对话"按钮，或使用键盘快捷键 Ctrl+N，即可开始一段全新对话，历史记录不受影响。

==========================================================
第二章 核心功能使用
==========================================================

2.1 切换 AI 模型
点击顶部工具栏中的模型选择下拉菜单，可选择：
- deepseek：DeepSeek Chat，通用问答首选
- deepseek-r1：DeepSeek R1，复杂推理与数学问题首选（会展示思维链）
- qwen：通义千问 Plus，中文文档处理首选

2.2 调整生成参数
点击顶部"参数"按钮可展开调节面板：
- Temperature（温度）：范围 0～2，数值越低回答越确定，越高越有创意，默认 0.7
- Max Tokens（最大长度）：范围 256～8192，控制单次回答的最长字数，默认 2048

2.3 设置系统提示词
点击顶部"系统提示"按钮，可为当前会话设置角色设定或背景指令。例如：
"你是一位专业的法律顾问，回答时请引用具体法条，语言严谨简洁。"
系统提示词仅在当前会话生效，不影响其他会话。

2.4 上传图片
点击输入框左侧的图片图标，或直接将图片粘贴到输入框（Ctrl+V），可上传最多 4 张图片。
上传后可继续输入文字描述你的问题，发送后 AI 将综合分析图片与文字内容。

2.5 语音输入
点击麦克风图标开始录音，Ayer 使用浏览器内置语音识别将语音转为文字填入输入框。
语音语言可在"设置→语音语言"中切换（支持中文、英语、日语等）。

2.6 联网搜索
点击输入框旁的地球图标开启联网搜索，再次点击关闭。
开启后 AI 会先检索互联网获取最新信息，适合询问：
- 当天新闻和热点事件
- 实时股价、汇率、天气
- 近期发布的软件版本、政策法规

2.7 知识库问答
进入"知识库"功能页（需管理员开启），先上传文档，上传完成后在知识库聊天窗口提问，
AI 会从你的文档中检索最相关的段落并给出答案，答案末尾会显示引用来源。

==========================================================
第三章 会话管理
==========================================================

3.1 搜索历史消息
点击左侧边栏顶部的搜索图标（或 Ctrl+K），输入关键词可全文搜索所有历史对话内容，
点击结果可直接跳转到对应消息位置。

3.2 收藏重要消息
将鼠标悬停在消息上，点击星形图标可收藏该条消息。
左侧边栏"收藏"区域可查看所有已收藏消息，方便快速回顾。

3.3 编辑与重新生成
- 编辑：悬停消息 → 点击编辑图标 → 修改内容后保存，AI 会基于修改后内容重新回答
- 重新生成：悬停 AI 消息 → 点击刷新图标，AI 将重新生成该条回答

3.4 从指定位置分叉
悬停任意消息 → 点击"分叉"图标，将以该消息为起点创建一个新会话分支，
原会话内容完整保留，适合对同一问题探索不同方向。

3.5 置顶与分组
右键单击左侧会话列表中的会话，可进行：
- 置顶：会话始终显示在列表顶部
- 移入文件夹：为会话指定分类文件夹
- 重命名：修改会话标题

3.6 分享会话
点击顶部"分享"按钮，生成公开分享链接，任何人无需登录即可通过链接查看该会话内容（只读）。
再次点击"取消分享"可撤销该链接的访问权限。

3.7 导入导出
- 导出：点击顶部"导出"按钮，可将当前会话导出为 JSON 或 Markdown 文件
- 导入：点击左侧边栏底部"导入"按钮，选择 JSON 文件恢复历史会话

==========================================================
第四章 键盘快捷键
==========================================================

| 快捷键       | 功能                     |
|------------|------------------------|
| Ctrl+Enter | 发送消息                   |
| Enter      | 换行（默认）/ 发送（设置后）        |
| Ctrl+K     | 打开全局搜索                 |
| Ctrl+,     | 打开设置                   |
| Ctrl+/     | 查看快捷键帮助                |
| Escape     | 停止当前生成 / 关闭弹窗          |

==========================================================
第五章 设置说明
==========================================================

点击左下角头像或"设置"按钮进入设置页：

5.1 通用设置
- 字体大小：小 / 中（默认）/ 大
- 发送方式：Ctrl+Enter 发送（默认）/ Enter 发送
- 默认模型：设置新建会话时的默认模型

5.2 语音设置
- 语音语言：zh-CN（普通话）/ en-US（英语）/ ja-JP（日语）等

5.3 提示词模板管理
可在此创建、编辑、删除常用系统提示词模板，在会话中一键应用，无需每次手动输入。

5.4 数据管理
- 清空所有会话：删除全部历史对话（此操作不可恢复，系统会弹出确认对话框）

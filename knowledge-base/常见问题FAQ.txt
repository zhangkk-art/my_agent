Ayer AI 智能对话助手 — 常见问题解答（FAQ）
更新日期：2025年3月

==========================================================
一、基础使用问题
==========================================================

Q1：Ayer 支持哪些语言？
A：Ayer 的 AI 模型支持中文、英文、日文、法文、德文、西班牙文等主流语言，中英文效果最佳。
   界面语言目前仅提供中文版，英文版本正在开发中，预计 2025 年 Q3 发布。

Q2：我的对话记录会保存多久？
A：对话记录永久保存在本地数据库中，不会自动删除。
   如需清理，可在"设置→数据管理"中手动清空，或在侧边栏右键删除单个会话。
   注意：清空操作不可恢复，请提前导出重要会话。

Q3：如何导出我的对话记录？
A：点击会话顶部工具栏的"导出"图标，选择格式：
   - JSON 格式：包含完整元数据，可重新导入 Ayer
   - Markdown 格式：适合阅读和归档，无法再导入

Q4：Ayer 可以同时进行多个对话吗？
A：目前版本不支持多窗口并行对话，但你可以快速切换不同会话，每个会话的上下文独立保存。

Q5：AI 的回答被截断怎么办？
A：回答被截断通常是因为达到了 Max Tokens 限制。可以：
   1. 点击消息旁的"续写"按钮，AI 将从断点继续输出
   2. 在参数设置中提高 Max Tokens 值（最高 8192）
   3. 将问题拆分为多个更小的子问题分别提问

Q6：能不能中途停止 AI 的回答？
A：可以。在 AI 输出过程中，点击输入框旁的停止按钮（■），或按 Escape 键，即可立即停止生成。
   已生成的内容会保留，你可以点击"续写"按钮从断点继续。

==========================================================
二、模型与质量问题
==========================================================

Q7：DeepSeek、DeepSeek R1 和 Qwen 有什么区别？应该选哪个？
A：
   - DeepSeek Chat：综合均衡，中英双语俱佳，适合日常问答、写作、编程，推荐作为默认选项
   - DeepSeek R1：具备"思考过程"展示，会先进行逐步推导再给出答案，适合数学题、逻辑推理、复杂分析；速度比 Chat 稍慢
   - Qwen Plus：阿里云模型，对中文文档和表格理解较好，适合处理中文合同、报告等材料

Q8：AI 给出了错误的信息怎么办？
A：AI 可能会"幻觉"（生成看似合理但实际错误的信息），尤其是涉及：
   - 具体数字、统计数据
   - 近期发生的事件（训练截止日期之后）
   - 专业领域细节（医疗、法律、金融）
   建议：对重要信息开启联网搜索验证，或通过提示词要求 AI 引用来源。

Q9：为什么开启联网搜索后回答变慢了？
A：开启联网搜索后，系统会先调用搜索 API 获取结果（约 1-3 秒），再将结果注入提示词，因此比普通对话慢一些，这是正常现象。

Q10：Temperature 参数怎么设置最好？
A：根据使用场景选择：
   - 0～0.3：代码生成、数据分析、事实性问答（需要确定性答案）
   - 0.5～0.8：日常对话、文档整理（均衡，推荐默认）
   - 1.0～1.5：创意写作、头脑风暴、诗歌生成（更有创意和多样性）
   - 1.5 以上：极度随机，通常不推荐

==========================================================
三、知识库（RAG）问题
==========================================================

Q11：知识库支持哪些文件格式？
A：支持以下格式：
   - PDF（.pdf）：包括扫描版 PDF（需含可选文字层）
   - Word 文档（.docx、.doc）
   - 纯文本（.txt）
   - Markdown（.md）
   - HTML 网页（.html）
   - PowerPoint（.pptx）部分支持
   不支持：纯图片 PDF（无文字层）、Excel 表格（.xlsx）

Q12：上传的文档有大小限制吗？
A：单个文件建议不超过 50MB，超大文件会导致解析时间过长。
   文档文字量建议不超过 50 万字，超过后分块数量增多会影响检索精度，建议拆分后分别上传。

Q13：知识库问答和普通问答有什么不同？
A：
   - 普通问答：AI 仅基于自身训练知识回答，无法获取你的私有信息
   - 知识库问答：AI 先从你上传的文档中检索最相关的段落（Top 5 段），再结合自身能力生成回答，并在回答中标注文档来源
   知识库问答更适合需要引用具体文档内容的场景。

Q14：删除文档后，已有的对话记录会受影响吗？
A：不会。删除文档只会从知识库索引中移除该文档，历史对话内容不会改变。
   但后续新提问将无法检索到已删除的文档内容。

Q15：为什么知识库问答没有找到我想要的内容？
A：可能原因：
   1. 问题描述与文档中的表达方式差异较大 → 尝试换不同的关键词或表达方式提问
   2. 相关内容在文档中出现在图片或表格中 → 当前版本对图片内文字和复杂表格支持有限
   3. 文档分块切割恰好将关键信息切断 → 后续版本会优化分块策略

==========================================================
四、隐私与安全问题
==========================================================

Q16：我的对话内容会被发送到哪里？
A：你的消息会被发送到 AI 模型提供商的 API 服务器（DeepSeek 或阿里云）进行处理，这是 AI 推理的必要步骤。
   对话历史存储在你自己部署的本地 MySQL 数据库中，不会上传到任何第三方平台。

Q17：生成的分享链接安全吗？
A：分享链接使用随机生成的 12 位字母数字 Token（约 56 亿种组合），外部无法枚举猜测。
   但分享链接本质上是公开的，知道链接的人均可访问——请勿分享包含敏感信息的会话。
   随时可在会话设置中点击"取消分享"立即撤销访问权限。

Q18：知识库中的文档安全吗？
A：文档解析后以文本块的形式存储在 Elasticsearch 中，原始文件不会保留在服务器上（仅保存文件名和元信息）。
   如果你部署在内网环境，只有内网用户才能访问知识库。

==========================================================
五、故障排查
==========================================================

Q19：消息发出后一直转圈，没有响应怎么办？
A：请按以下步骤排查：
   1. 检查网络连接是否正常
   2. 检查后端服务是否正常运行（访问 http://localhost:8080/api/conversations 是否有响应）
   3. 查看浏览器控制台（F12）是否有报错信息
   4. 检查 AI 模型 API Key 是否有效、余额是否充足
   5. 尝试刷新页面后重新发送

Q20：上传文件到知识库失败怎么办？
A：常见原因：
   1. Elasticsearch 服务未启动 → 确认 ES 在 localhost:9201 正常运行
   2. 嵌入模型 API Key 无效（DashScope）→ 检查 DASHSCOPE_API_KEY 环境变量
   3. 文件损坏或格式不支持 → 尝试转换为 TXT 格式再上传
   4. 文件内容为空或全为图片 → 当前版本不支持纯图片文档

Q21：联网搜索功能报错怎么办？
A：检查 WEB_SEARCH_API_KEY 环境变量是否配置了有效的 BochaAI API Key。
   BochaAI 提供每月 1000 次免费额度，超出后需充值。
   API Key 可在 https://open.bochaai.com 注册获取。
